# Review your GitHub portfolio

Share a GitHub profile or repository URL. Tell the assistant who you want to reach, such as employers, clients, collaborators or people who may reuse the project.

You receive a short assessment and up to five ranked improvements. Each improvement includes a source link, why it matters and a concrete change to make. The review may also suggest work worth sharing when there is enough evidence and it can be shared responsibly.

## Start here

After installing the plugin, ask:

> Review this GitHub repository for a potential client. What should I improve so they can understand the work and my contribution? [repository URL]

Open Claude Code by running `claude` in your terminal. In the Claude Code conversation, type `/github-portfolio-builder:github-portfolio-builder` followed by the target URL. Do not enter that slash command at the terminal prompt.

Public reviews need access to current pages. Private reviews require access you already have. The assistant provides recommendations in chat. The host's permissions control which tools it can use.

Read the [plugin guide](../../README.md) for installation and examples. The [working instructions](SKILL.md) define the review steps and evidence requirements.
